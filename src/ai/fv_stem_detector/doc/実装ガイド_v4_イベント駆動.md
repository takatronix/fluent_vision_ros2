## 実装ガイド v4（イベント駆動・関数分割・日本語コメント方針）

作成: 2025-08-17 / 対象: `fv_stem_detector`

### 目的
- YOLOトリガ型（LastOne方式）の実装を、関数単位に明確化して保守性を高める。
- すべての主要箇所に簡潔な日本語コメントを付与し、後工程（AparaDetection/表示）との連携を円滑化する。

---

## 全体フロー（YOLOトリガ）
1) Color/Depth は購読して「最新1枚（LastOne）」を保持するだけ。
2) YOLO（Detection2DArray）受信時に、最新Color/Depthのスナップショットを取得。
3) YOLO BBox → `StemRegion` 生成（スコア/サイズでフィルタ）。固定矩形も併用する場合は追加入力。
4) 各 `StemRegion` を 2D もしくは 3D パイプで処理。
5) `StemDetectionArray` と（3D時）`StemVectorArray` を発行。オーバーレイ画像は任意で発行。

---

## 関数分割（推奨構造）

### 1. 入力管理
- `void onColorAsync(const Image::ConstSharedPtr msg)`
  - 役割: 最新カラー画像の保存のみ（LastOne）。
  - 早期Return: `msg==nullptr`。
  - コメント: 「最新カラーの更新のみ。処理は行わない」。

- `void onDepthAsync(const Image::ConstSharedPtr msg)`
  - 役割: 最新深度画像の保存のみ（LastOne）。
  - 早期Return: `msg==nullptr`。
  - コメント: 「最新深度の更新のみ。処理は行わない」。

- `bool snapshotLatestFrames(Image::ConstSharedPtr &color, Image::ConstSharedPtr &depth)`
  - 入力: なし（内部ミューテックスで最新をコピー）
  - 出力: 成功時 true（両者が揃っている）
  - コメント: 「YOLOトリガ時に使用。取得できない場合は処理をスキップ」。

### 2. YOLO受信と領域生成
- `std::vector<StemRegion> buildRegionsFromYOLO(const Detection2DArray &yolo)`
  - 役割: class/score/サイズでフィルタし、`StemRegion` を生成。`yolo_score` を設定。
  - コメント: 「2D信頼度（YOLO score）はここで保持して後段表示に使用」。

- `void appendFixedRegionsIfEnabled(std::vector<StemRegion> &regions)`
  - 役割: `fixed.enable=true`なら固定矩形を追記。
  - コメント: 「ハサミの誤検出回避用に常時監視」。

### 3. ROI処理（2D / 3D）
- `StemDetectionResult processRegion2D(const cv::Mat &bgr, const cv::Mat &depth, const StemRegion &r)`
  - 手順: 2D形状抽出→最下点→Depthバリデーション→`StemDetectionResult` 作成。
  - 計測: morph/cc/pick/depth_fix/total の計測を内部で行い、`duration_ms` に合算。
  - コメント: 「2D方式（軽量）。cut-pointはpx基準」。

- `bool computeApproachDepthMedian(const cv::Mat &depth, const cv::Rect &roi, int window_px, int min_valid, double depth_scale_m, double &out_z_m)`
  - 役割: アプローチZの中央値を求めるユーティリティ。
  - コメント: 「3D方式のZ帯抽出の起点」。

- `bool processRegion3D(const cv::Mat &bgr, const cv::Mat &depth, const StemRegion &r, StemDetectionResult &cut, StemVector &vec)`
  - 手順: ROI→アプローチZ→Z帯→PassThrough(Y)→Voxel→SOR→PCA→root/tip/length/conf。
  - 出力: `cut`（rootをcutとみなす）と `vec`（root/tip/dir/length/conf）。
  - コメント: 「3D方式（PCA）、可視性はDepth有効時にtrue」。

### 4. 出力作成
- `fv_stem_detector::msg::StemDetection buildStemDetectionMsg(const StemDetectionResult &res, const Image::ConstSharedPtr &color, const cv::Mat &depth16u)`
  - 役割: camera系（必須）と visible/observed_at を埋めた `StemDetection` を返す。
  - コメント: 「world系は別途TFで埋める（失敗時NaN）」。

- `void fillWorldIfPossible(const geometry_msgs::msg::Point &camera_xyz, const rclcpp::Time &stamp, geometry_msgs::msg::Point &world_xyz)`
  - 役割: TFからworldへ変換。失敗時は NaN を設定。
  - コメント: 「短いタイムアウトで非ブロッキング」。

- `fv_stem_detector::msg::StemVector buildStemVectorMsg(const StemVector &vec, const Image::ConstSharedPtr &color)`
  - 役割: camera系（必須）＋任意でworld系を埋めて返す。
  - コメント: 「header.stamp=Colorのstamp」。

### 5. 可視化/ログ
- `void drawOverlayFrame(cv::Mat &img, ...)`
  - 役割: 矩形/アプローチ点/root/tip/軸/ラベルの描画。行0にYOLO%、行2にPCA%。
  - コメント: 「重すぎる場合は発行オフで軽量運用」。

- `void logProfileFrame(...), void logProfileROI2D(...), void logProfileROI3D(...)`
  - 役割: Nフレーム毎にINFOログ。過剰ログを避ける。

## 日本語コメントの指針（例）
- 関数ヘッダ直上に1-3行で「目的／前提／戻り値・副作用」。
- 早期リターン時は理由を1行で記載（例: 「最新のDepthが未取得のためスキップ」）。
- 例外は基本的に捕捉して警告ログ＋スキップにし、処理を止めない。

```cpp
// 目的: YOLOのBBoxからStemRegion配列を生成する
// 前提: Detection2DArrayのbbox/scoreが有効
// 戻り: フィルタ済みのStemRegion配列（yolo_score設定済み）
std::vector<StemRegion> buildRegionsFromYOLO(const Detection2DArray &yolo);
```

---

## 早期リターンとバックプレッシャ
- `event.skip_if_busy=true` のとき、処理中は新規YOLOを上書き保持のみ。
- 最新Color/Depthがどちらか欠ける場合は即スキップ。
- 出力購読者が0なら重い処理は行わない（可視化/配列とも）。

---

## 出力とI/F（再掲）
- `StemDetectionArray`: cut-point中心（camera系＋v4.1でworld/visible/observed_at）
- `StemVectorArray`: root/tip/dir/length/conf（3D時）

---

## 実装順序（推奨）
1) LastOne保持とYOLOトリガ骨格（onDetections→snapshotLatestFrames→処理）
2) YOLO score保存・オーバーレイの2D/3D信頼度分離
3) 2Dパイプの関数切り出し＋プロファイル
4) 3Dパイプの関数切り出し＋プロファイル
5) `StemDetection`拡張フィールド（visible/observed_at/world_*）の埋め込み
6) `StemVectorArray`の発行

以上。
