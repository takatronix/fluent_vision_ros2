## アスパラ茎検出ノード 設計書（C++）

### 目的
- 複数のチェック領域（矩形）内でアスパラ茎の最下点（カットポイント）を検出
- カラー画像に矩形と赤丸を重畳して公開
- 各領域の `region_id, x, y, detected` を配列で公開

### パッケージ/ノード
- パッケージ: `fv_stem_detector`
- ノード: `stem_detector_node`（実行名）

### インターフェース
- 購読
  - `camera_topic`: `sensor_msgs/Image`（BGR8）
  - `depth_topic`: `sensor_msgs/Image`（16UC1 等）
  - `pointcloud_topic`: `sensor_msgs/PointCloud2`（将来拡張）
- 発行
  - `output_annotated_image_topic`: `sensor_msgs/Image`
  - `output_detection_fixed_topic`: `fv_stem_detector/StemDetectionArray`（固定領域の結果）
  - `output_detection_yolo_topic`: `fv_stem_detector/StemDetectionArray`（YOLO動的領域の結果）

#### 出力トピック詳細
- **`output_annotated_image_topic`**: `sensor_msgs/Image`（`BGR8`）
  - 入力カラー画像に、固定領域=赤枠、YOLO領域=青枠、検出点=赤丸を重畳
  - `header` は入力カラー画像のものを継承。`frame_id` は `publish_frame_id`（既定 `fv_d405_color_optical_frame`）
- **`output_detection_fixed_topic`**: `fv_stem_detector/StemDetectionArray`
  - パラメータ `check_regions`/`check_regions_flat` で与えた固定矩形領域に対する検出配列
- **`output_detection_yolo_topic`**: `fv_stem_detector/StemDetectionArray`
  - サブスクライブした `vision_msgs/Detection2DArray` の各BBoxを領域化した検出配列。`region_id` は到着順連番

メッセージ定義
```
msg/StemDetection.msg
int32 region_id
int32 x
int32 y
bool detected

msg/StemDetectionArray.msg
fv_stem_detector/StemDetection[] detections
```

### メッセージ
```
msg/StemDetection.msg
int32 region_id
int32 x
int32 y
bool detected
float32 camera_x
float32 camera_y
float32 camera_z

msg/StemDetectionArray.msg
fv_stem_detector/StemDetection[] detections
```

### パラメータ
- 入力/出力トピック名: `camera_topic`, `depth_topic`, `pointcloud_topic`, `output_*`, `detection_topic`
- カメラ内参: `camera_info_topic`（`sensor_msgs/CameraInfo`）
- 深度スケール[m]: `depth_scale_m`（例: 0.001）
- チェック領域
  - YAML 側: `check_regions: [{id,x,y,w,h}, ...]`
  - ノード側: `check_regions_flat: [id,x,y,w,h, ...]`
- 描画: `overlay.rect_color_bgr`, `overlay.rect_thickness`, `overlay.cut_point_color_bgr`, `overlay.cut_point_radius`, `overlay.cut_point_thickness`
- 追加描画: 固定領域=赤(`overlay.fixed_rect_color_bgr`), YOLO領域=青(`overlay.yolo_rect_color_bgr`)
- その他: `publish_frame_id`, `publish_rate`, `qos.input_*`, `qos.output_*`

### 処理フロー
1. `message_filters::ApproximateTime` でカラー/深度を近似同期
2. 各 `check_region` に対して ROI を切り出し
3. 画像処理（ベースライン）
   - グレースケール → ぼかし → Canny → モルフォロジ閉（3x9）
   - 連結成分で縦長度（h/w）と面積からスコアリングして最良を選択
   - 最良成分の最下点画素を抽出
   - 深度が無効なら上方小窓で代替点を探索
4. 検出配列 `StemDetectionArray` を作成・発行
5. カラー画像に矩形と赤丸を重畳して発行（固定=赤矩形、YOLO=青矩形）

### 座標系
- `x,y`: カラー画像基準のピクセル座標（左上原点, x右+, y下+）
- `camera_x,camera_y,camera_z`: カメラ光学座標系（REP 103）で[m]。一般に Z: 前方+, X: 右+, Y: 下+

### 将来拡張
- カットポイントの 3D 座標出力（ピクセル+深度→カメラ座標）
- 点群併用の外乱除去・軸推定強化
- 学習ベース/色ベースの識別器追加

### 起動例
```bash
ros2 run fv_stem_detector stem_detector_node \
  --ros-args --params-file /ros2_ws/config/fv_stem_detector_d405.yaml \
  -r __node:=fv_stem_detector_d405
```
