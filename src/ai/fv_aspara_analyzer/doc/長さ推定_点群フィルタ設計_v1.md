## 長さ推定のための点群フィルタ設計 v1

作成日: 2025-08-16 / 対象: `fv_aspara_analyzer`

### ゴール
- 検出BBoxから「アスパラ本体のみ」を安定抽出し、長さ推定のために背景点群を抑制する。
- D405/D415それぞれに最適な初期パラメータと調整手順を提示（ビルド無しでYAML/パラメータ更新のみ）。

### 処理概要（legacy準拠・現行設計）
1) ROI確定: 検出BBoxをカラー座標で取得。
2) 近距離帯z0推定: ROI下部帯の列ごと最小深度から「もっとも手前の列」を検出し、その深度を基準 z0 とする。
3) 前景抽出: z基準（z0 または アプローチ深度）±しきい/背面カットで背景を除去。中央縦帯と横半径で横方向の混入を抑制。必要に応じて色/セグで補助。
4) ノイズ除去: VoxelGrid(ダウンサンプル) → StatisticalOutlierRemoval(SOR)。
5) ルート/下端クリップ: 根本より下の点を除去（可視化・長さ安定化）。

関連実装（参考）: `legacy/src/aspara_analyzer_thread.cpp` の ROI→z0→前景抽出→Voxel/SOR→root clip。

## パラメータ一覧（長さ推定・フィルタ関連）

- 入力/距離
  - `pointcloud_distance_min` / `pointcloud_distance_max`: 処理対象とする有効距離レンジ[m]
  - `depth_unit_m_16u`: 16UC1深度のメートル換算係数（D405=0.0001, D415=0.001）
  - `use_color_camera_info`: 近似的にカラー内参で写像（カラー整列深度ならtrue）

- ROI/抽出帯（画像空間）
  - `band_alpha`: 中央縦帯の相対幅（0..1）。小さいほど横方向の背景混入を抑制。
  - `hist_band_bottom_ratio` / `hist_band_top_ratio`: ROI下辺からの下部帯比率（z0推定用のスキャン帯）。
  - `root_depth_percentile`: z分布からz0を取る分位（既定p10）。

- 前景抽出（深度ベース）
  - `simple_z_back_cut`: z基準の背面カット（真後ろを一律に除去）。
  - `z_back_cut_m`: 背面カット距離[m]。
  - `back_cut.use_approach_depth`: z基準をz0からアプローチ点深度へ切替（D415で有効推奨）。
  - `back_cut.approach_max_delta_m`: z0との差がこの値以内ならアプローチ深度を採用。
  - `back_cut.use_min_with_z0`: z基準に min(z0, approach_z) を使用（安全側）。
  - `back_cut.z_ref_bias_m`: 参照深度を手前にバイアス（背景面混入の安全マージン）。
  - `root_lateral_radius_m`: 根本x周りの横半径制限[m]（背景面の横ずれ混入を抑制）。
  - `aspara_filter_distance`: 追加距離窓[m]（対象軸周りの深度窓）。

- 色/セグ補助（必要時のみ）
  - `enable_region_recognition`: 有効化トグル。
  - `root_use_segmentation`: セグ/色を使用するか。
  - `root_hsv_h_min/max`, `root_hsv_s_min`, `root_hsv_v_min`: 緑域のHSVフィルタ。

- ノイズ除去
  - `voxel_leaf_size`: VoxelGridの葉サイズ[m]（細かいほど形状保持・点数増/重く）。
  - `noise_reduction_neighbors` / `noise_reduction_std_dev`: SORの近傍点数Kと標準偏差しきい。

- クリップ/長さ
  - `root_clip_enable` / `root_clip_margin_m`: 根本より下側の除去。
  - `length.pca.trim_low` / `length.pca.trim_high`: PCA長測定の分位トリム。
  - `length.clip.min_m` / `length.clip.max_m`: 表示/評価の長さレンジ。
  - `length.method`: "chord"/"pca"/"skeleton"/"auto"（初段は"chord"推奨）。

- 表示・上限制御
  - `ui.filtered_points_max`: 右パネル等に貼る点群の上限点数（ベンチマーク時は0=無制限）。

## 現状設定（要点比較）

### D405（`config/fv_aspara_analyzer_d405.yaml`）抜粋
- 距離: `pointcloud_distance_min=0.25`, `max=1.5`, `depth_unit_m_16u=0.0001`, `depth_unit_auto_override=true`
- 抽出帯: `band_alpha=0.60`, `hist_band_bottom_ratio=0.04`, `hist_band_top_ratio=0.12`, `root_depth_percentile=0.10`
- 背面カット: `simple_z_back_cut=true`, `z_back_cut_m=0.12`, `back_cut.use_approach_depth=false`, `z_ref_bias_m=0.01`
- 横半径: `root_lateral_radius_m=0.04`
- 色/セグ: 全許容（HSV無効化）
- ノイズ除去: `voxel_leaf_size=0.004`, `noise_reduction_neighbors=20`, `noise_reduction_std_dev=1.0`
- 長さ: `length.method="chord"`, `length.pca.trim=[0.10,0.90]`, `length.clip=[0.08,0.40]`

所感:
- D405は近接高精度のため、ボクセル4mm・SOR K=20でも形状保持と速度のバランスは良好。HSV無効化でまず幾何のみの安定性確認を優先。背面カットはやや浅め(12cm)。

### D415（`config/fv_aspara_analyzer_d415.yaml`）抜粋
- 距離: `pointcloud_distance_min=0.05`, `max=2.0`, `depth_unit_m_16u=0.001`
- 抽出帯: `band_alpha=0.60`, `hist_band_bottom_ratio=0.04`, `hist_band_top_ratio=0.12`, `root_depth_percentile=0.10`
- 背面カット: `simple_z_back_cut=true`, `z_back_cut_m=0.18`, `back_cut.use_approach_depth=true`, `z_ref_bias_m=0.01`
- 横半径: `root_lateral_radius_m=0.04`
- 色/セグ: HSV有効な推奨値（H=35–85°, S≥0.25, V≥0.20）だが既定は `enable_region_recognition=false`
- ノイズ除去: `voxel_leaf_size=0.006`, `noise_reduction_neighbors=20`, `noise_reduction_std_dev=1.0`
- 長さ: `length.method="chord"`, `length.pca.trim=[0.05,0.95]`, `length.clip=[0.08,0.40]`

所感:
- D415はFOV/距離が広め。背面カット距離を大きめ(18cm)にして背景面の混入に対処。アプローチ深度採用でz基準を安定化。

## 検証手順（ビルド不要・動的調整）

前提: ノード名は例として D415=`/fv_aspara_analyzer_d415`, D405=`/fv_aspara_analyzer_d405`。

1) ベースライン確立（色/セグOFF）
   - `enable_region_recognition=false`, `root_use_segmentation=false` を確認。
   - `length.method="chord"`、`length.clip=[0.08,0.40]` を適用。

2) 背面カットの最適化
   - D415: `z_back_cut_m` を 0.15→0.22 で段階調整。背景混入と点数のトレードオフを見る。
   - D405: 0.10→0.14 で同様に確認。

3) 中央帯・横半径の調整
   - `band_alpha` を 0.50–0.70 で確認。
   - `root_lateral_radius_m` を 0.03–0.05 で背景面の横ずれ混入を抑制。

4) Voxel/SOR の最適化
   - `voxel_leaf_size` をレンジ内で調整し、形状保持と処理負荷のバランスを取る。
   - `noise_reduction_neighbors`/`noise_reduction_std_dev` を増減し、孤立点/外れ値を除去。

5) 根本クリップの確認
   - `root_clip_enable=true`, `root_clip_margin_m≈0.02` で長さ推定の安定化を確認。

6) 長さ安定性の評価
   - 静止対象でフレーム間長さ変動CV(%)<5% を目標。
   - 実測物差しとの誤差±1.5cm以内（D405近接）/±2.5cm以内（D415中距離）を暫定合格ラインに設定。

動的設定例（D415）:
```bash
ros2 param set /fv_aspara_analyzer_d415 z_back_cut_m 0.20
ros2 param set /fv_aspara_analyzer_d415 band_alpha 0.55
ros2 param set /fv_aspara_analyzer_d415 voxel_leaf_size 0.008
ros2 param set /fv_aspara_analyzer_d415 noise_reduction_neighbors 30
ros2 param set /fv_aspara_analyzer_d415 noise_reduction_std_dev 0.8
```

## 観測・可視化ポイント
- 点数と分布
  - フィルタ後点群（右パネル/トピック）点数: 目安 D405=2k–8k、D415=1k–6k（距離・解像度依存）。
  - 下部帯のzヒストグラムの最浅ピーク（z0）が安定していること。
- 形状
  - 背景面の大塊が残らない（矩形境界や棚面が消えている）。
  - 断面の太さが急変しない（過度なSORで細りすぎない）。

## 既知の注意
- D405は `depth_unit_m_16u=0.0001`。自動上書きはD405のみ許可（`depth_unit_auto_override=true`）。
- D415は `back_cut.use_approach_depth=true` が有効。アプローチ深度とz0が乖離するシーンでは `approach_max_delta_m` を見直す。
- 色/セグは初段ではOFF推奨。幾何で安定後にONへ。

# 抽出帯
band_alpha: 0.60
hist_band_bottom_ratio: 0.04

  approach_max_delta_m: 0.06

# クリップ/長さ
root_clip_enable: true
root_clip_margin_m: 0.02
length:
  method: "chord"

    enable: true
    min_m: 0.08
    max_m: 0.40

    trim_low: 0.05
