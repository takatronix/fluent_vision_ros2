# アスパラ選択情報 仕様書

作成日: 2025-08-14
対象ノード: `fv_aspara_analyzer_node`
読者: ロボット側実装者（選択中アスパラを購読して制御する人）

## 目的
- 画面/内部で選択されたアスパラを一意に把握し、ロボットへ渡すインターフェースを統一する。
- 次/前への選択操作と、その結果の反映を明確化する。

## 用語
- アスパラID: 検出寿命中に一意な整数ID。`AsparaSelection`が採番・維持。
- 選択中アスパラ: 現在UI/ノード内部でフォーカスされている1本。

## 選択操作（ROS2サービス）
- ノード起動時に2つのサービスを提供します。
  - `next_asparagus: std_srvs/Trigger`
    - 次のアスパラを選択。成功で`success=true`。
  - `prev_asparagus: std_srvs/Trigger`
    - 前のアスパラを選択。成功で`success=true`。

例（D405ノード名を仮に`/fv_aspara_analyzer_d405`とする）:
```bash
ros2 service call /fv_aspara_analyzer_d405/next_asparagus std_srvs/srv/Trigger {}
ros2 service call /fv_aspara_analyzer_d405/prev_asparagus std_srvs/srv/Trigger {}
```

注意: 複数カメラ（D405/D415）を並行起動する場合、各ノード名に対して個別に呼び出してください。

## 選択の決定ロジック（概要）
- 初回: 最も近い（矩形面積が大）+ 信頼度で最適候補を自動選択。
- 以降: `next/prev`で循環移動。消失時は最適候補へリカバリ。

## 選択中アスパラの可視化
- 画像上: 選択中アスパラは強い線/彩度で描画。
- 付随情報: ID, 信頼度(未設定0%または将来導入), 長さ, 太さ, 真直度(曲がり度), グレード, 距離など。
- アプローチ点: 矩形中心にピンクの丸（輪）を表示（YAMLでON/OFF可能）。

## 選択中アスパラ情報の提供
- 現行実装: トピック公開の有効化フラグと名前、周期を YAML で制御
  - `selected_asparagus_info_enabled: true`
  - `selected_asparagus_topic`: 例）D405: `/fv/d405/selected_asparagus_info`、D415: `/fv/d415/selected_asparagus_info`
  - `selected_asparagus_publish_rate`: 例）10.0
- 推奨メッセージ（簡易案）:
```text
std_msgs/Header header
int32 id
float32 length_m
float32 diameter_m
float32 straightness_0_1
geometry_msgs/Point root_world
geometry_msgs/Point approach_world
geometry_msgs/Point32 approach_pixel  # x,y, z=0
bool is_harvestable
```
  

## YAML パラメータ（抜粋）
- 選択可視化/ウィンドウ:
  - `left_panel_enabled`, `right_panel_enabled`
  - `voxel_window.position`: `left` | `right`
  - `voxel_window.overlay_enabled`: true/false
- アプローチ点:
  - `approach.enable`: true/false
  - `approach.overlay.enable`: true/false
  - `approach.y_mode`: `center`（推奨）
  - `approach.overlay.thickness`: 2（輪表示）

## ロボット側の利用フロー（推奨）
1. カメラごとのノードに`next_asparagus`/`prev_asparagus`をサービス呼び出しして選択を操作。
2. 専用トピック（将来追加予定）を購読し、選択中アスパラの`id`, `approach_world`, `root_world`, `length_m`等を取得。
3. `approach_world`へアームを接近 → 条件合致で切断/収穫。

## 複数カメラ運用
- ノード名で区別（例: `/fv_aspara_analyzer_d405`, `/fv_aspara_analyzer_d415`）。
- サービスは各ノード名の名前空間下に存在。
- 将来の情報トピックも`/fv/d405/...`, `/fv/d415/...`で分離提供。
