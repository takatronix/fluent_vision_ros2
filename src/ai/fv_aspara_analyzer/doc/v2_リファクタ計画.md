### v2 リファクタ計画（ゼロベース再構築）

方針:
- 既存コードは参照のみ。`v2/` 名前空間・ファイルに新実装を作成
- 段階的に差し替え可能なよう、ビルド切替フラグをCMakeに用意

新規ファイル（提案）:
- `include/.../v2/overlay_engine_v2.hpp` / `src/.../v2/overlay_engine_v2.cpp`
- `include/.../v2/aspara_visualizer_v2.hpp` / `src/.../v2/aspara_visualizer_v2.cpp`
- HUDは `fluent_lib/ui` の `Renderer`, `HUDWidget` を活用。必要なα合成は `ui/alpha.hpp` に整理

移植順:
1. OverlayEngineV2（補間ロジック + スナップショット）
2. VisualizerV2（パススルー描画 + オーバーレイ + タイトル + 情報枠雛形）
3. 情報ウィンドウ（Renderer＋alpha合成）
4. YAMLバインディング（パラメータ宣言・既定値・型整合）

切替:
- ノード内で `use_visualizer_delegate_v2: true` の場合にV2を使用

注意点:
- 単位/丸め/レンジチェックは必ず描画直前に適用
- αブレンドは一時レイヤで合成してから貼り付け（文字が薄くならないよう）
