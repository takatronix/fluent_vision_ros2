## 点群処理設計書 v2（カメラ別・最小構成から段階導入）

作成日: 2025-08-16 / 対象: `fv_aspara_analyzer`

### 目的
- パラメータの乱立を回避し、長さ・曲がり・太さ推定に必要な「点群処理」のみを段階導入。
- まずは最小セット（BBox ROIからアプローチZ±帯の点群抽出）を確実に動かす。

---

## 現在のv2最小仕様（実装済み）

1) 対象の選択: 画面/UIは現状維持。選択中アスパラのBBoxを取得。
2) アプローチ点の深度: 近傍中央値で `approach_z` を算出（既存の `approach.depth.*` パラメータ準拠）。
3) ROI点群抽出: 検出BBox（`fv_stem_detector/StemDetectionArray` 由来の領域中心から生成される矩形）を深度解像度に合わせ、ROI内各画素を内参でx,y,zへ復元。
4) 深度バンドでフィルタ: z ∈ [approach_z − minus, approach_z + plus] の点のみ採用。
5) 出力: x,y,z,rgb(float32) の `sensor_msgs/PointCloud2` を公開（カメラ別トピック）。

備考: UIは現状のまま（枠/ラベル/HUD）。点群の重い後処理（Voxel/SOR等）はまだ導入しない。

## 最小パラメータ（v2段階1/実装済み）

- 深度単位/参照
  - `depth_unit_m_16u`: 16UC1→m 変換（D405=0.0001, D415=0.001）
  - `use_color_camera_info`: true 既定（カラー整列深度）

- 深度バンド（新・最小）
  - `depth_band.enable` (bool, 既定 true)
  - `depth_band.minus_m` (double, 既定 0.05)  ← アプローチ点 − 5cm
  - `depth_band.plus_m`  (double, 既定 0.05)  ← アプローチ点 ＋ 5cm

- アプローチ点深度（既存）
  - `approach.depth.window_px` (既定 5)
  - `approach.depth.min_valid` (既定 5)
  - `approach.depth.strategy`  (median|mean, 既定 median)
  - `approach.depth.max_range_m` (既定 2.0)

※ UI系・ID管理系の設定は現状維持。段階2以降に必要最小のみ追加予定。

## 段階導入プラン（Step-by-Step）

- Step 1（完了）: ROI抽出 + アプローチZ±バンドのPC2出力（カメラ別）
  - パラメータ: `depth_band.enable/minus_m/plus_m`

- Step 2: 計測可視化の最小HUD
  - 右パネルに「点群数」「アプローチZ（cm）」の2行を追加（負荷ゼロに近い）
  - パラメータ追加なし（既存HUDのテキストだけ）

- Step 3: 軽量の横方向/中央帯フィルタ（背景抑制）
  - `band_alpha`（中央縦帯の相対幅）、`root_lateral_radius_m`（横半径）を最小追加
  - 既定: D405=0.60/0.04, D415=0.60/0.04

- Step 4: Voxel/SOR の最小導入（オフ）→段階的にON
  - `voxel_leaf_size`, `noise_reduction_neighbors`, `noise_reduction_std_dev`
  - 既定はOFF相当（未指定は処理スキップ）→値設定時だけ適用

- Step 5: 長さ（chord）算出・表示
  - 方針: ROI点群の主軸or骨格の両端（下端/上端）から弦長を計測→HUD表示
  - パラメータ: `length.method: "chord"` のみ（他方式は先送り）

- Step 6: 太さ・曲がり（最小）
  - PCA径（直径）と直線度（簡易）を導入。必要時にのみ計算（フラグ）
  - パラメータ: `metrics.enable`、`metrics.straightness.kappa_ref` など最小限

## D405/D415 推奨初期値（段階1〜3向け）

- 共通（段階1）
  - `depth_band.enable: true`
  - `depth_band.minus_m: 0.05`
  - `depth_band.plus_m: 0.05`

- D405
  - `depth_unit_m_16u: 0.0001`
  - 段階3で `band_alpha: 0.60`, `root_lateral_radius_m: 0.04`

- D415
  - `depth_unit_m_16u: 0.001`
  - 段階3で `band_alpha: 0.60`, `root_lateral_radius_m: 0.04`

## テスト手順（段階1）

1) ノード起動（D415の例）
```bash
ros2 run fv_aspara_analyzer fv_aspara_analyzer_node --ros-args \
  --params-file config/fv_aspara_analyzer_d415.yaml \
  -r __node:=fv_aspara_analyzer_d415
```

2) パラメータ調整（帯幅）
```bash
ros2 param set /fv_aspara_analyzer_d415 depth_band.minus_m 0.05
ros2 param set /fv_aspara_analyzer_d415 depth_band.plus_m 0.05
```

3) 出力確認
```bash
ros2 topic echo /fv/d415/aspara_analysis/roi_band_points | head -n 20
```

4) RViz確認（PointCloud2）
  - フレームは深度画像の `frame_id` を踏襲。

## 受入れ基準（段階1）
- 選択中アスパラのBBoxに応じて、アプローチZ±帯の点群が安定して出力される。
- 近傍が背景面のみの場合は点数が極端に少なくなる（=帯で切られている）。
- パラメータ変更は即時反映（ROS2 param）。

---

## 今後の拡張（段階2以降）
- HUDへ点群統計（点数、z中央値）と長さ（chord）の表示。
- 段階的に `band_alpha` / `root_lateral_radius_m` / `voxel_leaf_size` / `noise_*` を導入。
- 計算コストは常に最小化。未使用の機能は完全オフ。
