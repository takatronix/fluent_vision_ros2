# カーソル仕様（v2）

目的
- 選択対象（アスパラ）に対する「視線・操作カーソル」を導入し、選択制御とUIを安定化する。
- 仕様はコードから独立し、実装は専用クラスに分離して保守性を確保する。

用語・座標系
- カーソル座標: 画像のピクセル座標（左上原点、x右+, y下+）。
- アスパラ矩形: YOLO等の検出BBox（画像ピクセル座標）。
- 時間: ms 単位。keepCursorTime を ms で表現。

状態管理
- On/Off の2状態を持つ。デフォルト Off。
- On 中はカーソルに追従するスムーズアニメーションを適用する（平滑時間可変）。
- Off から On へ自動遷移: 画面にアスパラが1つでも出現したら即 On（出現対象の閾値判定は「アスパラノードの表示対象ロジック」に委譲。カーソル側では行わない）。
- On 維持条件: keepCursorTime は「直下に有効な対象が見つからなくなってからの経過時間」。直下に対象が存在する間はタイマーを延長し続ける（＝リセット）。

優先順位（Off→On 時の自動選択）
- YAML `aspara_selection.sort` に従う（既定: area）。
  - area: 面積最大
  - confidence: 信頼度最大
  - tie-breaker: 面積→信頼度→左上に近い（任意）
  - カーソル直下で複数ヒットした場合も「面積→信頼度」の順で決定

YAML パラメータ（例）
```yaml
cursor:
  enabled: true             # カーソル機能を有効化（既定: true）
  keep_ms: 5000             # keepCursorTime（ミリ秒、既定: 5000）
  smooth_time_ms: 150       # アニメの平滑時間（小さいほど速く追従）
  color_bgr: [0, 255, 0]    # 緑の十字
  size_px: 20               # 十字の半サイズ
  thickness_px: 2
  auto_on: true             # Off時に対象出現で自動On
  auto_off_if_miss: true    # keep_ms で直下に対象が無ければ自動Off
  input_topic: "/fv/cursor/click"  # 任意: クリック等入力（geometry_msgs/Point）
```

クラス設計（別ファイルに分離）
```cpp
// UiCursorController.hpp（案）
class UiCursorController {
public:
  // 指定位置へカーソルアニメーション開始（位置はピクセル）
  void SetPosition(int x, int y);
  // 表示/非表示制御
  void ShowCursor();
  void HideCursor();
  bool IsShown() const;
  // 現在のカーソル位置（スムーズ後）
  cv::Point GetPosition() const;

  // 時間更新（dt秒）。アニメ平滑・タイムアウト判定を内部更新
  void Tick(double dt_seconds);

  // 自動ロジック: Off時に highestPriorityRects から1つ選び On＋中心へ移動
  // On時はカーソル直下にある矩形のIDを返す（なければ -1）
  int UpdateAutoLogic(const std::vector<std::pair<int, cv::Rect>>& rects);

  // 設定
  void Configure(int keep_ms, int smooth_ms, cv::Scalar color, int size_px, int thickness_px,
                 bool auto_on, bool auto_off_if_miss);
};
```

処理フロー
- Off 状態:
  1) 画面にアスパラがある場合、優先度（`aspara_selection.sort`）で1つ選ぶ
  2) `ShowCursor()`、選んだ矩形の中心に `SetPosition()`
  3) On に遷移し、`keep_ms` カウント開始
- On 状態:
  1) カーソル直下にあるアスパラIDを強制選択（それ以外は非選択）
  2) 直下に対象が存在する間は `keep_ms` を延長（タイマーリセット）
  3) 直下に対象が見つからなくなってから `keep_ms` 経過で `HideCursor()`（Off）
  3) 直下に対象がある場合は On を維持（再カウント or 継続は実装設定）

描画
- 十字カーソル（横線・縦線）。Clipは画像範囲内。
- 色・サイズ・太さは YAML から取得。
- スムーズは一次遅れ: `alpha = clamp(dt / smooth_time, 0..1)`、`cur = cur + (target-cur)*alpha`。

選択との連携
- On: `UpdateAutoLogic()` が返すIDを `selected_id_` に直接適用。
- Off: 既存の選択ロジック（最大面積など）で `selected_id_` を決定。

インプット（任意・RQT連携）
- `geometry_msgs/Point` を受け付ける `input_topic` を購読可能。
- クリック受信で `ShowCursor()`＋`SetPosition(x,y)`。
- RQT 連携を想定し、以下のインターフェースも任意で提供可能:
  - サービス: `/fv/cursor/show`・`/fv/cursor/hide`（`std_srvs/Trigger`）
  - テレオペ用途の `/fv/cursor/set_position`（`geometry_msgs/Point`）
  - トピック名は自由に変更可能（YAML `cursor.input_topic` で設定、既定 "/fv/cursor/click"）

エッジケース
- 画像解像度が変わる場合: カーソルは常に「現在の表示画像」の座標系とする。
- 複数BBoxがカーソル直下: 優先度規則で1つに決定。
- 追従中の対象消失: keep_ms カウントにより On→Off を自動判定。

実装メモ
- カーソルは `fv_aspara_analyzer` から独立した小クラス（`UiCursorController`）で実装。
- スレッドセーフ要件は基本不要（描画スレッド内運用）。必要に応じて最小ロック。
- 既存の `OverlayEngine` の更新周期（ui.fps）で `Tick()` を呼ぶ。

遅延と整合性ポリシー（重要）
- YOLOの検出・矩形は遅延して到着することを前提とする（ネットワーク/スケジューラの都合）。
- クリックなどの即時操作は「最新に到着済みの矩形集合」に対してのみ判定を行う。
  - 面積降順に並べ替えたリストに対し、クリック座標のヒットチェックで最初に一致したものを強制選択。
  - 後から検出が到着しても、矩形が合致（同一領域）していればそのまま継続利用する。
- 画像は常に右→左（input→output）へ一方向に流す。過去フレームへの巻き戻しは行わない。
- UIは検出と同期させない。検出が無いフレームでも、最新の選択状態とカーソルで描画を継続する。
- ID管理はフレーム間のIoU等で緩やかに接続し、軽微な遅延や揺らぎで選択が破棄されないようにする（面積→信頼度の優先）。
