# フィールドタグ印刷物 (field_tags)

tag36h11 ファミリの AprilTag を使ったフィールド用マーカーの印刷物一式。
走行・作業エリアのゾーン表示（侵入禁止 / 停止 / 徐行 / ホーム / 行の起点・終点）と、
個体識別マーカー（親茎: 採取禁止）を含む。

- `sheets/` — **A4 まとめ刷りシート（これが正、300DPI 原寸）**。ハサミ用の薄グレー
  切り取り線付き。校正 ID0×12 / 親茎 12 枚×3 シート / フィールド系 150mm 各種。
  キューブ面のシートは `../cube_kit/sheets/`。単品 PDF は廃止（シートから切る）

> ⚠ **寸法の読み方（重要）**: 表の「タグ寸法」は 10×10 ブロック（**規格上の白リング
> 1 セルを含む**）の呼び寸法で、**切り取り後の紙もこの寸法ちょうど**（切り取り線＝
> 図案の縁）。**黒い正方形はその 0.8 倍**（呼び 50mm → 黒 40mm、
> 呼び 150mm → 黒 120mm）。検出器の `tag_size` は**黒枠の実寸**を使う
> （呼び 50mm 印刷 → `tag_size: 0.040`。2026-07-12 に全 config を修正済み）。
> クワイエットゾーンは図案内の白リング＋白 PLA マウントの縁で確保される。
> **濃い色の面に直貼りする時だけ**、線の外に白を 5mm ほど残して切ること。

> **ID の正本は `fluent_vision_ros2/src/ai/fv_apriltag/config/tag_registry.yaml`。**
> ID 割り当ての追加・変更は必ず先に registry を更新し、印刷物・マウント・
> 下流の config はその registry に追従させること。本 README の表は registry の
> 人間可読ミラー。

## 2色プレート（3Dプリント、校正グレード）

紙より歪み・反射・段差がなく、**校正用途の常設タグはこちらが正**。
`../tag_plates/tag_plate_flat_idNNN_*.3mf`（白黒PLA Matte 2色、面がベッド接地=段差ゼロ）。
ID 0(CALIB) / 10–13(隅) は 50mm、ID 20(DOCK) / 30–33(畝) /
110–113(再localization) は 150mm を生成済み。
**隅タグの常設は `../cube_kit/stl/mounts/tag_corner_stand_50mm.stl`**（テーブルの角に
2辺のリップで引っ掛けて自己整合するスタンド。裏返し=ポケット面をベッドにして印刷）。
全プレートは生成時にメッシュ由来の盤面を実検出器でデコード検証済み。

## サイズの根拠（50mm と 150mm）

AprilTag の検出可能距離の目安は **おおよそタグ一辺の 20〜30 倍**（カメラ解像度・
レンズ・照明で上下する）。用途ごとのカメラ距離に合わせて 2 サイズを使い分ける。

| タグ寸法 | 想定カメラ | 想定距離 | 検出目安（一辺 ×20〜30） |
|---------|-----------|---------|------------------------|
| **50mm** | アームカメラ（近距離） | 0.2〜0.5 m | 〜1.0〜1.5 m まで |
| **150mm** | 走行カメラ（遠距離） | 1〜3 m | 〜3.0〜4.5 m まで |

- **50mm = 近距離用**: アーム先端カメラが 0.2〜0.5m まで寄って読む個体識別（親茎など）向け。
- **150mm = 遠距離用**: 走行体のカメラが 1〜3m の距離から読むゾーン表示・
  再localization向け。圃場では照明・角度・汚れを含め実測して距離上限を決める。

## マウント対応表（3D プリント）

紙タグは `sheets/` の切り取り線（=図案の縁、**呼び寸法ちょうど**）で切り、マウントの
0.6mm ポケットに落とし込むと自己整合する（糊付け推奨）。
マウント STL は `../cube_kit/stl/mounts/`。**全パーツ Bambu A1 mini（180mm ベッド）
にそのまま収まるサイズ**。

| タグ呼び寸法 | 紙サイズ（切り取り線） | ペグ（地面差し込み・縦向き） | スタンド（平置き・上向き） |
|---------|----------------------|----------------------------|--------------------------|
| 50mm（黒40） | **50mm** | `tag_peg_paper50_tag50.stl`（一体、全長170mm） | `tag_stand_paper50_tag50.stl` |
| 150mm（黒120） | **150mm** | 未生成（150mm用を設計してから使用） | 未生成（150mm用を設計してから使用） |

- **ペグ**: 角スパイク＋先端くさびで地面に差し込み、タグ面を**縦（側面向き）**に保持。
  側面視カメラ・側方アプローチ向け。旧100mm用STLを150mm印刷物へ流用しない。
- **スタンド**: 平らなタイルでタグ面を**上向き**に保持。ベンチ・マット上での置き用

## 印刷時の注意

- **倍率 100%（等倍）で印刷する。** プリンタの「用紙に合わせる / フィット」は必ず OFF。
- 印刷後、**黒い正方形の実寸を定規で確認**: 呼び 50mm タグ → **黒 40mm**、
  呼び 150mm タグ → **黒 120mm**。ずれていたら倍率設定を疑う。
- **屋外設置はつや消し（マット）ラミネート推奨。** 光沢ラミネートは反射で検出率が落ちる。
- キャプション（`idNNN <ラベル>`）は識別用。**タグ本体（黒白パターン）を折り目・汚れ・
  影で欠けさせない**こと。
- 親茎マーカーは ID が個体識別なので、**どの個体に何番を貼ったかを必ず記録**する。

## 再生成

```bash
# A4シート（切り取り線付き、これが正）
python3 fluent_vision_ros2/src/ai/fv_apriltag/tools/generate_tag_sheets.py \
    --out-dir <field_tags>/sheets --cube-kit-out <cube_kit>/sheets
# マウントSTL
python3 fluent_vision_ros2/src/ai/fv_apriltag/tools/generate_tag_mounts.py \
    --out-dir <cube_kit>/stl/mounts
# タグ画像は AprilRobotics/apriltag-imgs から取得し ~/.cache/fv_apriltag/tag_imgs/ にキャッシュ。
```

キャプションフォントは DejaVu（CJK グリフ無し）のため、**印刷キャプションは ASCII のみ**。
日本語の用途説明は本 README（画面表示用）に置く。
