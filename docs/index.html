WHY FLUENTVISION

Stop hand-rolling launch files.

Real-world robot perception is usually a tangle of hard-coded topics, copy-pasted model loaders, and zero runtime introspection. FluentVision flips that around.

🧩

Pipelines are data

Declare your camera → AI → streaming graph in a YAML file. No hidden state, no launch-file logic creeping into Python.

🖱️

Edit in a browser

Drag, drop, wire nodes together, preview live frames over WebSocket, hit Save. Out comes a runnable pipeline.

🧠

Batteries included

YOLOE open-vocabulary detection, YOLO-seg, Depth Anything V3, AprilTag cubes, 3D OBB, FoundationPose bridge — all ready to drop in.

⚡

Real-time first

BEST_EFFORT QoS by default, TensorRT / ONNX Runtime backends, optimized for Jetson Orin and AGX Thor.

🎥

Stream anywhere

MJPEG for browsers, WebSocket for dashboards, RTMP for OBS, binary WS for point clouds. Run them all in parallel.

📼

Episode-ready

One node captures synchronized rosbag + per-camera MP4 + markers + sidecar JSON — straight into LeRobot / Pi0.5-friendly layouts.

ANATOMY OF A PIPELINE

Plain YAML. No magic.

The editor reads, writes, and visualises exactly this format. Version-control it, diff it, share it.

name: "Object Detection"
description: "RealSense D405 → YOLO → overlay + MJPEG"

nodes:
  - id: camera_d405
    package: fv_realsense
    exec: fv_realsense_node
    parameters:
      serial: "230322270366"
      enable_color: true
      enable_depth: true

  - id: detector
    package: fv_object_detector
    exec: fv_object_detector_node
    parameters:
      input_topic:  /fv/d405/color/image_raw
      output_topic: /fv/objects/detections
      model: yolov10s.onnx

  - id: mjpeg
    package: fv_mjpeg_server
    exec: fv_mjpeg_server_node
    parameters:
      input_topic: /fv/objects/overlay
      port: 8080

QUICKSTART

From clone to live detections in 60 seconds.

Assuming ROS 2 Humble, an Intel RealSense camera, and a CycloneDDS-capable environment.

# 1. Clone into a ROS 2 workspace
cd ~/ros2_ws/src && git clone https://github.com/takatronix/fluent_vision_ros2.git

# 2. Build (default copy-based — do NOT pass --symlink-install)
cd ~/ros2_ws
colcon build --packages-up-to fv_pipeline_editor fluent_vision_system
source install/setup.bash

# 3. CycloneDDS is required (FastRTPS conflicts with librealsense2)
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp

# 4. Launch the visual editor
ros2 run fv_pipeline_editor editor_node
#    → open  http://localhost:8095

Now drag a RealSense node and a YOLOE node onto the canvas, wire them up, hit Run.
Live detections in your browser, in under a minute.
