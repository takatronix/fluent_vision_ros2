# アスパラ分析 外部インタフェース仕様書（2025-08-18）

この文書は D405/D415 の2カメラ運用時に、`fv_stem_detector` と `fv_aspara_analyzer` を操作するための外部インタフェース（トピック/サービス/起動方法）をまとめたものです。`config/` の各YAMLと整合しています。

ROS_DOMAIN_ID は各自の環境を尊重し、本書では固定・上書きしません。

## 名前空間と基本規約
- カメラごとの名前空間: `/fv/<camera>`（例: `/fv/d405`, `/fv/d415`）
- `fv_stem_detector` のサービスは `service.ns`（YAML）により `/fv/<camera>/stem_detector/...` で公開
- `fv_aspara_analyzer` のサービスはノードNSに依存せず、`service.ns`（既定は画像トピックから推定した `/fv/<camera>`）配下の絶対名で公開（例: `/fv/d405/get_selected_asparagus`）

## トピック
- カラー: `/fv/<camera>/color/image_raw`
- 深度: `/fv/<camera>/depth/image_rect_raw`
- カメラ情報: `/fv/<camera>/color/camera_info`

### fv_stem_detector 出力
- 注釈付き画像: `/fv/<camera>/stem_detector/result` (sensor_msgs/Image)
- 単一合成検出: `/fv/<camera>/stem_detector/detections` (fv_stem_detector/StemDetectionArray)
  - 備考: 固定/YOLOの個別出力は廃止し、単一の合成出力に統合
  - 備考2: 検出は3Dパイプライン（pointcloud_linefit）のみ。2D経路は廃止。

### fv_aspara_analyzer 出力
- 注釈付き画像: `/fv/<camera>/aspara_analysis/result` (sensor_msgs/Image)

### fv_stem_detector（モード切替）
- 名称: `/fv/<camera>/stem_detector/set_source_mode`
- 型: `fv_stem_detector/srv/SetSourceMode`
- リクエスト: `string mode`（許可: `object` | `fixed`）
- レスポンス: `bool success`, `string message`
- 例（object=YOLOに切替）:
```
ros2 service call /fv/d405/stem_detector/set_source_mode fv_stem_detector/srv/SetSourceMode "{mode: object}"
```
- 例（fixedに切替）:
```
ros2 service call /fv/d405/stem_detector/set_source_mode fv_stem_detector/srv/SetSourceMode "{mode: fixed}"
```
- 既定: `source.mode = "object"`

### fv_stem_detector（固定矩形の動的変更・保存）
- パラメータ（動的反映可）:
  - **fixed.rect**: 単一固定矩形 `[x, y, w, h]`
  - **fixed.rect_id**: 矩形ID（既定 0）
  - **fixed.save_yaml_path**: 保存先YAMLパス（空なら保存不可）
- 例（D405ノード名: `fv_stem_detector_d405`）:
```
ros2 param set /fv_stem_detector_d405 fixed.rect "[200, 120, 80, 200]"
ros2 param set /fv_stem_detector_d405 fixed.rect_id 0
ros2 param set /fv_stem_detector_d405 fixed.save_yaml_path "config/fv_stem_detector_d405.yaml"
```
- YAML保存サービス（`std_srvs/SetBool`）:
  - 名称: `/fv/<camera>/stem_detector/save_fixed_rect_yaml`
  - リクエスト: `{data: true}`（値は未使用）
  - レスポンス: `success`, `message`
  - 例:
```
ros2 service call /fv/d405/stem_detector/save_fixed_rect_yaml std_srvs/srv/SetBool "{data: true}"
```
  - 出力YAML例（最小）:
```
check_regions_flat: [0, 200, 120, 80, 200]
```
  - 保存動作の注意: `fixed.rect` 設定時、YAMLは「check_regions_flat 行のみ」インプレースで更新し、他の設定は保持します（行が無い場合は `ros__parameters:` 直後に挿入）。

### fv_object_detector（運用方針）
- しきい値の細かな調整は下流の `fv_stem_detector` 側で実施してください。
- `fv_object_detector` は粗めの足切りのみ（YAMLの既定値）で運用し、動的変更は行いません。
- 例（下流での調整）:
```
ros2 param set /fv_stem_detector_d405 yolo.min_confidence 0.45
ros2 param set /fv_stem_detector_d405 yolo.min_bbox_w 8
ros2 param set /fv_stem_detector_d405 yolo.min_bbox_h 12
```

（補足）パラメータでも切替可能:
```
ros2 param set /fv_stem_detector_d405 source.mode object
ros2 param set /fv_stem_detector_d405 source.mode fixed
```

### 表示フィルタの注意（固定モード）
- `fv_aspara_analyzer` の表示フィルタ（`filter.yolo.min_confidence`, `filter.pca.min_confidence`）は、固定モード（SOURCE_FIXED）の要素には適用しません。
- 固定モードの矩形は常に描画され、色は青で統一されます（長さ・収穫可否に依らず）。

### fv_aspara_analyzer（選択操作・情報取得）
- 名称: `/fv/<camera>/next_asparagus`（次を選択） 型: `std_srvs/Trigger`
```
ros2 service call /fv/d405/next_asparagus std_srvs/srv/Trigger {}
```
- 名称: `/fv/<camera>/prev_asparagus`（前を選択） 型: `std_srvs/Trigger`
```
ros2 service call /fv/d405/prev_asparagus std_srvs/srv/Trigger {}
```
- 名称: `/fv/<camera>/get_selected_asparagus`（選択中詳細） 型: `fv_aspara_analyzer/srv/GetSelectedAsparagus`
```
ros2 service call /fv/d405/get_selected_asparagus fv_aspara_analyzer/srv/GetSelectedAsparagus {}
```

### fv_aspara_analyzer（表示フィルタ・自動保存）
- 動的パラメータ（表示の間引き）:
  - `filter.yolo.min_confidence`: YOLO 2D信頼度のしきい値（0.0–1.0）
  - `filter.pca.min_confidence`: 3D PCA信頼度のしきい値（0.0–1.0）
- 固定モード（SOURCE_FIXED）には表示フィルタは適用しません（常に青で描画）。
- 自動保存:
  - `filters.save_yaml_path` を設定しておくと、上記パラメータ変更時に即保存します。
  - `filters.save_yaml_path` が空で `config.source_file` が設定されている場合は、そちらを保存先に使用します。
  - 保存は YAML の `filter:` ブロックをインプレース更新し、他設定は保持します（`filter:` が無ければ `ros__parameters:` 直後に挿入）。

## 起動例
```
ros2 run fv_stem_detector fv_stem_detector_node --ros-args \
  --params-file config/fv_stem_detector_d405.yaml \
  -r __node:=fv_stem_detector_d405

ros2 run fv_aspara_analyzer fv_aspara_analyzer_node --ros-args \
  --params-file config/fv_aspara_analyzer_d405.yaml \
  -r __node:=fv_aspara_analyzer_d405
```

## よく使う確認コマンド
```
ros2 service list | grep -E "/fv/(d405|d415)/" | cat
ros2 topic info /fv/d405/stem_detector/detections | cat
ros2 node info /fv_aspara_analyzer_d405 | grep -A2 Subscribers | cat
ros2 run image_view image_view --ros-args -r image:=/fv/d405/aspara_analysis/result | cat
```

## トラブルシューティング
- D415の情報がD405へ混ざる: `fv_aspara_analyzer` の `camera_topic` を正しく設定（既定で `camera_topic` から `/fv/<camera>` を自動抽出）。ノードの `__ns` 指定は不要。
- サービスが見つからない: `fv_stem_detector` および `fv_aspara_analyzer` の `service.ns`（既定 `/fv/<camera>`）を確認。
- 画像が出ない: 入力画像トピックとQoS（best_effort）を確認。

## config との突合せ（主要）
- `config/fv_stem_detector_d405.yaml` / `config/fv_stem_detector_d415.yaml`
  - `camera_topic`, `depth_topic`, `camera_info_topic`
  - `output_annotated_image_topic`, `output_detection_topic`（= `/fv/<camera>/stem_detector/detections`）
  - `service.ns: "/fv/<camera>"`
  - `source.mode: "object"|"fixed"`（既定 "object"）
- `config/fv_aspara_analyzer_d405.yaml` / `config/fv_aspara_analyzer_d415.yaml`
  - `camera_topic`, `depth_topic`, `camera_info_topic`, `detections_topic`（既定 `/fv/<camera>/stem_detector/detections`）
  - `output_annotated_image_topic`
  - サービス: `service.ns`（既定 `/fv/<camera>`）、および尾名（tail）: `services.get_selected`, `services.next`, `services.prev`
